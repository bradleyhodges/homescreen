# Contributing

Use the Node/pnpm versions in README. Install from the committed lockfile, keep changes focused, and run `pnpm check` and `pnpm build` before submitting changes.

Use Conventional Commits with an app, package or subsystem scope. Describe the problem, resulting behavior and validation. Include regression tests for meaningful behavior and failure paths. Do not include local credentials, real Home Assistant entity dumps or proprietary assets.

Use the shared UI package and narrow Home Assistant hooks. See AGENTS.md for architecture and lifecycle requirements. Resolve the release/license status in README before treating this repository as licensed open-source material.
